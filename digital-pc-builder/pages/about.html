About the project

Digital PC Builder

A web-based virtual compatibility and simulation system that helps beginners, students, enthusiasts and retailers plan PC builds without costly mistakes.

Project goals

  • Prevent incompatible purchases with automated, explained compatibility checks.
  • Help users stay within budget with transparent, usage-aware recommendations.
  • Give realistic expectations through clearly labeled performance and power estimates.
  • Make comparing parts and complete builds simple and visual.

Technology

  • Frontend: HTML5, CSS3 and vanilla JavaScript (ES6), with no build tools.
  • Backend: PHP REST endpoints (backend/api) with PDO.
  • Database: MySQL / MariaDB (backend/database.sql).
  • Fallback: without the backend, the catalog loads from data/components.json and builds are kept in localStorage.
  • Charts: Chart.js via CDN, with a built-in CSS fallback when offline.

Hardware dataset

Compatibility rules

  1. Socket: CPU socket must equal motherboard socket; flags boards that may need a BIOS update for newer CPU generations.
  2. Memory: RAM generation (DDR4/DDR5) must match the board; module count, capacity and rated speed are checked against board limits.
  3. Form factor: the case must list the motherboard form factor (E-ATX, ATX, Micro-ATX, Mini-ITX).
  4. GPU clearance: GPU length vs. case maximum; under 15 mm spare is a warning.
  5. Cooler: socket support, rated capacity vs. CPU TDP and peak power, air-cooler height or radiator size vs. case.
  6. Power: estimated peak draw vs. PSU wattage, recommended PSU (peak × 1.3, rounded up to 50 W, at least the GPU vendor's recommendation), 16-pin connector and PSU form factor.
  7. Storage: M.2 slot and SATA port counts, PCIe generation, and 2.5"/3.5" drive bays.

Estimation model

  • Each CPU has relative single-core, multi-core and gaming indices; each GPU has raster and ray-tracing indices (normalized from general public benchmark trends).
  • Gaming FPS = min(CPU frame capacity, GPU frame capacity). CPU capacity = gaming index × 2.0 × RAM factor; GPU capacity = GPU index × resolution factor (1080p 2.4, 1440p 1.75, 4K 0.95) × preset factor. Shown as a range of −15% to +12%.
  • Bottleneck = the gap between CPU and GPU capacity. GPU-bound is normal; CPU-bound above 20% is flagged.
  • Temperatures: CPU = 40 °C + 55 °C × (heat under the workload ÷ cooler rating), so a cooler at its full rating reaches the ~95 °C limit (stock coolers count as 95 W). GPU = 35 °C + 40 °C × GPU load. Cases with few fans or a small interior add 2 to 9 °C.
  • Workload scores are weighted sums of CPU, GPU, RAM and storage factors, normalized so a reference build scores 100.
  • Recommendations score compatible candidates by usage fitness (50%), budget fit (30%) and value (20%), and list the reasons behind each pick.
